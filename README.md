# 🌤️ Weather Intelligence App

An AI-generated, deployment-ready weather application built with **Google AI Studio App Build**, powered by the **Open-Meteo API**, and hosted on **Cloudflare Pages**.

---

## 📌 Overview

This project converts an AI-generated prototype into a fully functional, live-deployed web application. The **Weather Intelligence App** allows users to quickly search for cities worldwide, view real-time weather metrics, analyze extended forecasts, and receive tailored planning recommendations.

---

## ✨ Key Features

* **City Search & Geocoding:** Search for any city to instantly fetch real-time weather data.
* **Current Weather Overview:** View live updates for temperature, humidity, wind speed, and weather conditions.
* **7-Day Forecast:** Detailed 7-day weather outlook to plan ahead.
* **Planning Recommendations:** Intelligent weather-based suggestions to help users plan outdoor activities, travel, or daily routines.
* **Public API Integration:** Powered by the free, public [Open-Meteo API](https://open-meteo.com/).

---

## 🛠️ Tech Stack & Workflow

* **App Builder:** Google AI Studio App Build
* **Data Source:** Open-Meteo API
